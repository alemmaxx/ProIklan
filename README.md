# ProIklan: ambil data percuma

1. Buat repo GitHub baharu, muat naik semua fail dalam folder ini.
2. Repo > Settings > Pages > Source: "Deploy from a branch" > main > / (root).
3. Repo > Actions > "Kemas kini peraduan" > Run workflow (kali pertama). Selepas itu jalan sendiri setiap 6 jam.
4. Buka https://NAMA.github.io/NAMA-REPO/ . Slider Peraduan akan guna data/peraduan.json.

Tambah sumber: edit sources.json. Mana-mana blog WordPress ada RSS di https://namablog.com/feed/ .
Facebook dan Instagram tidak boleh diambil dengan cara ini.
Item yang ada frasa mencurigakan (contoh "yuran penyertaan") masuk senarai semakan Admin, bukan slider.
